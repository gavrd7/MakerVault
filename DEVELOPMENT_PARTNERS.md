# MakerVault Development Partners

MakerVault is an independent, open-source, self-hosted platform for maker projects, component and equipment inventories, filament and spools, RFID/NFC workflows, 3D printing, slicing and print history. It aims to support makers across different hardware ecosystems.

We welcome development collaborations with 3D printer manufacturers, hardware makers and other organisations who want to help improve interoperability.

## Why development hardware matters

An API or an initial connection does not prove an integration works safely and reliably on real hardware. Physical testing is needed to validate discovery, telemetry, file transfer, slicing and print submission, material mapping, multi-tool workflows, error handling and print completion. Supported capabilities depend on each model, firmware version and available interface.

## Ways to contribute

- **Evaluation hardware:** temporary loan units, refurbished printers or engineering samples for hands-on compatibility testing.
- **Technical assistance:** public or appropriately shareable protocol/API documentation, implementation guidance and engineering contacts.
- **Collaborative validation:** reproducible test cases, technical feedback and coordinated hardware testing.

A contribution does not guarantee particular features, deadlines or universal compatibility. Hardware loans should be agreed separately, including duration, shipping, return arrangements and responsibilities. MakerVault will not accept conditions that compromise honest technical reporting or its open-source obligations.

## Recognition for confirmed contributors

Subject to explicit permission and agreed branding usage, we can offer:

- Acknowledgement in MakerVault's **About / Development Partners** section when implemented.
- An approved company name, logo and website link in the GitHub repository and relevant documentation.
- Credit in relevant integration documentation and release notes.
- Public compatibility reports identifying physically tested hardware, firmware, supported features and known limitations.

We will not list any organisation as a partner until it agrees. Recognition is not an endorsement, paid advertisement, exclusivity arrangement or guarantee of certification.

## Independence and transparency

MakerVault remains independently developed, open-source and manufacturer-neutral. A hardware contribution cannot buy favourable coverage, suppress issues or direct technical conclusions. We distinguish hardware-verified integrations from community-tested or unverified work. Any third-party interfaces and slicing engines remain subject to their applicable licences and conditions.

MakerVault's main software repository is licensed under the **GNU Affero General Public License v3.0 (AGPL-3.0)**. Collaborations must respect this and applicable third-party licensing.
