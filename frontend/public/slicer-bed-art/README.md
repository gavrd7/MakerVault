# Native build-plate artwork

The Creality K1 and K2 SVGs in this directory are unmodified build-plate
textures bundled from **OrcaSlicer v2.4.2**, sourced from:

- [Creality K1 SVG](https://github.com/OrcaSlicer/OrcaSlicer/blob/v2.4.2/resources/profiles/Creality/creality_k1_buildplate_texture.svg)
- [Creality K2 SVG](https://github.com/OrcaSlicer/OrcaSlicer/blob/v2.4.2/resources/profiles/Creality/creality_k2_buildplate_texture.svg)

Source project: https://github.com/OrcaSlicer/OrcaSlicer

(SPDX: AGPL-3.0)**. The native art is attributed to the OrcaSlicer
contributors and upstream asset authors. This folder does not convey
MakerVault authorship or ownership of the images.

MakerVault uses these images only as *optional visual overlays* for exact
known printer/model and bed-size matches. They do not change printer
compatibility, selected plate temperatures, nozzle paths or build dimensions.
Unknown model variants must use generic preview graphics until their own
native artwork has been reviewed and bundled.
