# MakerVault Support

## Start with the user guide

The public guide is the best starting point for installation, configuration, updates, backups, HTTPS, accounts and integrations:

https://gavrd7.github.io/MakerVault-docs/

## Bugs

If MakerVault is behaving incorrectly, open a **Bug report** using the repository issue form.

Include:

- MakerVault version or commit;
- whether this was a fresh installation or an upgrade;
- your host OS and Docker/Compose versions where relevant;
- the affected feature;
- exact reproduction steps;
- what you expected to happen;
- what actually happened;
- sanitised logs or screenshots if useful.

Do not post passwords, API keys, session tokens, private backups, database dumps or other secrets.

## Feature requests

Use the **Feature request** issue form.

Explain the problem you are trying to solve, not only the implementation you have in mind. If the request concerns printer hardware or an external service, include the exact model/service and any useful public API or protocol documentation.

## Installation and configuration help

For deployment questions, first check:

- the installation guide;
- environment configuration;
- storage;
- backup and recovery;
- troubleshooting;
- reverse-proxy / HTTPS guidance.

If you still need help, open a bug report if something appears broken. For general questions, use a GitHub Discussion if Discussions are enabled; otherwise an issue is acceptable when the question is specific and reproducible.

## Security

Do not use normal issues for vulnerabilities.

See [SECURITY.md](SECURITY.md).
